**日期**：2025年3月13日  
**编写者**：[您的姓名]  
**客户**：和康医院  
**目标**：构建一个可定制的AI聊天界面，提升患者体验和临床工作效率，采用本地部署并通过中间服务器集成中国本地大语言模型（如DeepSeek、百度文心）。

## 概述

和康医院需要一个AI聊天解决方案，以优化患者交互并支持临床操作。该系统将以LibreChat为基础框架，定制医院专属品牌（LOGO、侧边栏）、管理功能，并与外部API及本地LLM集成。系统需适应中国大陆的网络限制，支持匿名患者会话，并为未来的计费和限流功能提供扩展性。

## 客户需求概要

### 第一部分：面向患者的功能

#### 1. 症状分析与科室推荐（预诊断）
- 患者输入症状，AI根据医学知识库分析，推荐科室/医生并判断紧急程度
- 示例：急性病症（发热、外伤）→内科/外科；慢性病症（高血压、慢性疼痛）→中医科
- 提供苏州健康12320平台的预约链接

#### 2. 智能客服与健康咨询
- 提供24/7 AI聊天机器人，回答常规问题、个性化健康建议（饮食、运动）及患者教育
- 支持医院每日健康宣教内容

#### 3. 全流程患者引导
- 指导患者完成挂号、就诊、检查、复诊、缴费和取药流程
- 提供医生诊室位置和就诊前检查建议，减少等待时间

### 第二部分：临床工作流功能

#### 1. 诊断推荐与证据
- 医生输入症状/检查结果，AI基于相似病例和指南建议诊断并提供证据
- 对照检查结果验证诊断（需结构化EMR模块）

#### 2. 检查结果分析
- AI解读实验室/影像结果，标记异常并根据患者历史预测疾病趋势（需LIS/PCAS集成）

#### 3. 医疗质量控制
- 检查医生处方/医嘱，依据用药安全和医保规则，标记错误或违规

#### 4. 数据驱动的洞察
- 分析医院数据（运营、模块使用情况），提供质量、安全和性能优化建议

## 实现细节

### 第一部分：面向患者的功能

#### 1. 症状分析与科室推荐
- **前端**：LibreChat聊天窗口中的文本输入，用于症状录入
- **后端**：自定义API端点（`/api/symptom-analyze`）查询中间服务器
- **中间服务器**：路由至DeepSeek LLM，提示：
  ```
  给定症状：[用户输入]，根据医学知识库分析。推荐科室（如内科、中医科）和紧急程度（急性/慢性）。返回苏州12320链接。
  ```
- **输出**：聊天回复包含科室、医生建议和预约链接
- **数据**：医院专家排班、临床知识库

#### 2. 智能客服与健康咨询
- **前端**：全天候聊天，预加载健康问答提示
- **后端**：通过中间服务器提供LLM驱动的回复
- **中间服务器**：个性化提示：
  ```
  患者提问：[问题]。根据和康医院数据提供个性化建议（饮食、运动）或医院信息。
  ```
- **输出**：对话式回复+教育内容

#### 3. 全流程患者引导
- **前端**：分步聊天提示（例如"下一步：挂号→就诊"）
- **后端**：API（`/api/journey-guide`）获取诊室位置、检查建议
- **中间服务器**：整合医院数据（专家位置、检查目录）与LLM，提供自然引导
- **输出**：动态聊天流程，含链接/按钮（例如"查看李医生诊室位置：A区"）

### 第二部分：临床工作流功能

#### 1. 诊断推荐与证据
- **前端**：医生在聊天中输入症状，UI显示建议
- **后端**：API（`/api/diagnosis-suggest`）查询EMR+中间服务器
- **中间服务器**：DeepSeek提示：
  ```
  症状：[输入]。根据指南和相似病例建议诊断并提供证据。
  ```
- **输出**：诊断列表+对照检查结果验证（未来EMR模块）

#### 2. 检查结果分析
- **后端**：API（`/api/test-analyze`）提取LIS数据，发送至中间服务器
- **中间服务器**：结合历史数据分析结果：
  ```
  检查：[结果]。标记异常，根据[患者历史]预测趋势。
  ```
- **输出**：医生聊天报告，含洞察

#### 3. 医疗质量控制
- **后端**：API（`/api/quality-check`）对照用药/医保规则检查医嘱
- **中间服务器**：标记违规（例如"药品X不在医保范围内"）
- **输出**：医生聊天中的警报

#### 4. 数据洞察
- **后端**：定时任务聚合使用数据，送至中间服务器
- **中间服务器**：分析趋势（例如高峰时段、错误率）
- **输出**：顶部栏的管理仪表板（未来功能）

Node.js应用，使用Express：
```javascript
const express = require('express');
const app = express();
app.post('/llm', (req, res) => {
  // 路由至DeepSeek，限流请求

});

```
